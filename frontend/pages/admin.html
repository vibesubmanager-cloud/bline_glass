Stripe payments

From Stripe Dashboard → Developers → API keys. Secret key starts with sk_live_ or sk_test_. Publishable key starts with pk_live_ or pk_test_. Webhook secret is optional, from Developers → Webhooks, endpoint /api/billing/stripe/webhook.

PayPal payments

From PayPal Developer Dashboard → Apps & Credentials. Use Live client ID and secret for real payments, or Sandbox keys for testing. Set Live/Sandbox on the Subscriptions page.
