Voice, camera, and privacy.

Test speaker

Tap a button. You should hear the same voice used on the camera, in earphones, and on iPhone. Turn the iPhone Ring switch on and turn volume up first.

Tap a test. If you hear it, that part of the speaker is working.

iPhone

Use Safari. Tap to speak. Hold for a command. Double tap to start or stop object detection.

If Safari still blocks the camera or microphone, install this certificate, then enable Vibe Eye Local in Settings → General → About → Certificate Trust Settings.

Location and map

Use Safari on the https page, tap Allow location, then Add to Home Screen. A home-screen app has its own GPS switch: Settings → AI Sight → Location → While Using the App.

Also turn on Settings → Privacy & Security → Location Services. Chrome on iPhone is less reliable; Safari is the one to save to the home screen.

For App Store and Play Store later, wrap this same app as a native shell. Then the phone GPS is used automatically.

On-phone object detection

Download YOLO once onto this phone. After that, double tap the camera for live boxes and spoken objects, even without waiting on the server. Use this before wrapping the app as an APK.
